Quickstart & Reproduction

Deployment & Execution in 3 Steps

Reproduce the exact experimental telemetry pipeline locally on your workstation.

STEP 1

Clone & Install Dependencies

Clone repository and install requirements via pip:

git clone https://github.com/anasaleemkhan/DataPulse-AI.git
cd DataPulse-AI
pip install -r requirements.txt
STEP 2

Configure Gemini API Key

Obtain a free key from Google AI Studio:

# PowerShell
$env:GEMINI_API_KEY="your-api-key"

# Linux / macOS
export GEMINI_API_KEY="your-api-key"
STEP 3

Execute Dual Interfaces

Launch Streamlit UI or headless CLI:

# Interactive Web Dashboard
streamlit run app.py

# Headless CLI Engine
python cli.py --data sample_urban_data.csv --lang en
